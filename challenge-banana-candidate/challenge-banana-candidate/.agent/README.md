# Flujo Integral de Desarrollo Asistido por Agentes (.agent)
Este directorio contiene la definición formal y ejecutable de los 7 agentes especializados diseñados por Maximo Porretti para gobernar el ciclo de vida completo del desarrollo de software: desde la captura del requerimiento hasta el empaquetado, verificación y subida final de la feature.

## Pipeline de Agentes:
1. `01-requirements.agent.md`: Captura y formalización de requerimientos, criterios de aceptación y alcance.
2. `02-architect.agent.md`: Arquitectura técnica, diseño de contratos, máquina de estados financieros e idempotencia.
3. `03-implementer.agent.md`: Implementación segura de transferencias, propuestas con TTL y reconciliación.
4. `04-agent-builder.agent.md`: Construcción del Operator Case Copilot, telemetría determinista y control de evidencia.
5. `05-qa-tester.agent.md`: Verificación continua, tests unitarios, integración HTTP y edge cases de red.
6. `06-code-reviewer.agent.md`: Auditoría de código independiente, seguridad de roles e integridad de invariantes.
7. `07-release-delivery.agent.md`: Compilación de producción, empaquetado ZIP reproducible, sesiones IA y entrega.
